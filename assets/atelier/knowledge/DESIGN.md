# Atelier · 现代视频信息层

用户认可素材盘点与柱状图样板的审美，并要求 17 个自制模板统一重设计；不要求所有模板都有背景框。默认水平居中，实际叠视频时再按主体调整，不能预留一整侧无意义空白。

## 共同规则

- 960×540 透明画布；主内容左右等距，通常为 x64、宽832。采用系统无衬线字体，标题26px、辅助14–19px、主数值44–86px。
- 石墨色底板 rgb(28 29 32 / 82%)、正文 #F4F4F5、辅助 #C5C7CE、次级图形 #888E99、强调 #DCE8E0。强调色只标出关键数据或当前节点。文字在完整展示阶段保持不透明。
- 主底板26px圆角、节点22px圆角、轻边界与弱阴影。去掉米白/墨绿/朱红组合、标题竖条、首位侧条和装饰性下划线。
- 不用持续漂浮、光晕、假百分比或杜撰增长结论。每种动作表达其用途：柱子长高、线条连接、关系依次建立、旧观点划除后出现修正。
- 每段6秒，后半段保持信息可读；入场透明，末尾由宿主切换。图表按真实数值共享尺度与零基线，不靠任意拉伸凸显差距。

## 各类容器

| 模板 | 结构 |
| --- | --- |
| column-reveal / series-trace / inflection-note | 居中图表底板；数值直接标注，轻量基线；拐点解释放在线下独立一行 |
| paired-values / option-balance | 双列均衡底板；同宽区域，层级靠字号与明度区分 |
| measure-bars / ordered-podium / percent-ticks | 紧凑数据底板；统一比例、清晰排行与真实部分刻度 |
| evidence-footnote / term-definition | 下方居中局部信息卡；来源或术语先行，解释后出现 |
| duo-overlay | 下方居中合计与双指标卡；比例条与两项数值严格对应 |
| state-handoff | 无外框；左右两个独立状态节点与中间箭头 |
| step-stair / cause-relay | 无外框；三个独立节点与接力箭头，不做阶梯偏置 |
| milestone-rail | 无外框；一条功能性轨道、三个小标签底板 |
| feedback-circuit | 无外框；四个局部节点、有限一次的回程连线 |
| correction-reveal | 单底板承接旧观点、划除和修正，保持连续阅读位置 |

## 参数与交付

`transparent=true` 为下载模板默认值；`panelOpacity` 在70–96之间，只影响底板。浮动标题与连线仍需结合真实视频检查可读性，当前不自动避让人物或字幕。统一审阅页可选择本地视频，不上传文件。

展厅 MP4 采用显式深色不透明背景，以保证普通视频播放器可见；这是预览条件，不能误称 MP4 有 alpha。源 HTML 保留透明画布。生成源是 theme.css、runtime.js 和 scripts/build_atelier_knowledge.py，不能只改生成文件。

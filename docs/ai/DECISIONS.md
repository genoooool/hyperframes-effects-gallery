# 当前设计决定

## 2026-09-11：自制动效的现代审美

用户认可独立素材盘点和柱状图的克制现代方向，否定旧米白/墨绿/朱红与装饰竖线，明确授权17个自制模板重做，并要求按内容决定是否需要背景框。

- 默认水平居中；真实视频中的主体避让属于具体接入，不预设左侧大块空白。
- 图表保留半透明底板，流程、状态、回路采用局部节点，阶段轨道可不使用外框。统一的是字号、配色、间距和运动节奏，不是同一大卡片。
- 下载源码默认透明画布，文字完整展示时不透明；展厅MP4显式使用深色背景。透明PNG与无alpha的MP4预览分别说明。
- 保留原模板ID及用途、真实参数和数据比例；不照搬参考库素材，不把技术检查当成用户创意验收。
- 初始授权是本地重设计。完成审阅后，用户回复“行，更新吧”，已授权将这版17个模板同步到网站与GitHub。发布沿用白名单静态包和现有Cloudflare域名，复用已验证样片。

如何使用

下载并解压模板包（内含 index.html、gsap.min.js、default.json），按 default.json 修改参数，用 HyperFrames 的 --variables-file 渲染。

下载模板包 查看使用说明 在展厅中预览与收藏

这是本地模板，不在官方 registry 中。不得使用 hyperframes add 安装。只替换已确认的文字、数据与颜色；默认数字是示例。

Atelier 独立编写的 HTML / SVG / GSAP 模板与样片。形式参考 nutllwhy/hyperframes-motion-library；未使用对方模板源码、文案或媒体。MP4 为不透明预览，透明导出需选择支持 alpha 的格式并核验。

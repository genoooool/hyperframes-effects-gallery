assemble-then-type-flyin

组件与文字分步飞入

空的暗底网格上，无文字的组件骨架先从四面八方飞入贴合；随后各处文字逐字从 3D 空间旋转着飞来落位，先大标题后小标注，全部落位后页面成形

适合用在哪里

页面/海报"自己长出来"的开场；排版类产品的能力展示；从骨架到成稿的两段式叙事

如何使用

读取原始配方卡 references/shots/effects/assemble-then-type-flyin.md，选择 assemble-then-type-flyin 分支；按卡片指向的 demos/ 实现复制所需组件与共享依赖，参照 demos/README.md 注册 Remotion Composition。

查看模板源码 查看使用说明 在展厅中预览与收藏

先读镜头配方卡并按其中的准确路径定位实现；同一卡可能包含多个动作分支，本项为 assemble-then-type-flyin。保留共享 Fixtures/Motion/PageCam 与所需纹理；依赖 Remotion 帧时钟，部分实现需要 motion-blur。示例文案、数字和图表不代表真实事实。

如何使用

读取原仓库 src/families/accessibility-captions.tsx、对应 registry 和 src/lib/ 依赖；使用预设 accessibility-captions-caption-box。这不是独立 npm 包。仓库根目录未提供明确许可证，正式复用前核对作者授权与第三方来源要求。
